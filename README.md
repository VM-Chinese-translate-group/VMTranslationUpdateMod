VM 汉化实用工具是一个为 Minecraft 整合包汉化补丁设计的自动化汉化管理工具，涵盖了绝大部分汉化相关的使用场景。

普通玩家可以通过它获得额外的模组资源包汉化，VM汉化组内部也可以通过它为玩家提供更好的汉化体验。

模组相关功能请查询 [VMTU 文档](https://docs.vmct-cn.top/vmtu/)。
